# VeriMundi Privacy Policy

Effective date: 2026-07-13

VeriMundi is a demo MVP that uses fictional local content. This policy describes the current Android demo release.

## Data We Do Not Collect

The current release does not create user accounts, collect names, collect email addresses, collect precise location, collect contacts, use advertising IDs, process payments, or upload saved-story data to a VeriMundi server.

## Data Stored on Your Device

When you save a story, VeriMundi stores a local snapshot on your device. The snapshot includes the fictional story ID, headline, country code, summary, verification status, source count, and saved time. This data is used only to show your Saved stories list.

You can remove a saved story in the app. Uninstalling the app removes the local app data according to Android platform behavior.

## Demo Content and AI Labels

Stories, sources, source counts, AI summaries, and AI answers in this release are fictional demo content. VeriMundi does not send your questions to a commercial GenAI provider in this release.

## Network and Third-Party SDKs

The current release is designed to run in mock data mode. It includes networking code for a future backend, but no live backend is enabled for the demo release. If crash reporting, analytics, or a backend is added in a later release, this policy and the Google Play Data Safety form must be updated before release.

## Children

VeriMundi is not directed to children. The Play Console target audience declaration should match the final store listing and content rating before production submission.
